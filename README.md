# BrodyBot

**Status:** 🚧 In Development

BrodyBot is a Discord bot that tracks the daily menus at Michigan State University's Brody Square dining hall.

Instead of simply displaying the full menu every day, BrodyBot remembers previous menus, identifies recurring items, and highlights what has changed between meals.

## Planned Features

- 🍳 Track breakfast on Saturdays and Sundays
- 🍽️ Track daily lunch and dinner menus
- 🧠 Remember previous menus using a local database
- 🔄 Detect added and removed menu items
- 📜 View full menus on request
- 📅 Search historical menus
- ✨ Display menus in a clean, easy-to-read Discord format
